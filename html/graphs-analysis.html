How to Read This Graph

This graph shows how respondents assess the necessity of disclosing generative AI use in scholarship. Each bar represents a response option. Options range from "very necessary" to "not necessary at all". The height of each bar indicates how many respondents selected that option.

The main filter above allows users to explore how views on disclosure vary by categories like "experience," "seniority," "discipline," or self-defined "genAI literacy." When a subfilter is applied, the chart updates to show responses only from that group. Values reflect the number of respondents who selected a given answer. On desktop view, users can also hover over a given bar to see percentages of respondents who selected a given option.

      How to Read This Graph

      These graphs combine responses to Q13 and Q14 to show how views on genAI disclosure vary by scholarly product type. The two graphs demonstrate that context matters for AI disclosure, and within each context scholars’ expectations vary.

      The pie chart (Q13) shows whether respondents believe the type of scholarly product has a bearing on the need for disclosure.

      The stacked bar chart (Q14) shows which scholarly products respondents believe to require genAI disclosure. Each bar represents a product type, and its total length reflects how many respondents selected it.

      Where Do AI Disclosure Expectations Align with Practice?

      Coming soon!

      How to Read This Graph

      This heatmap graph compares perceptions of what should be disclosed (Q15) with actual genAI use (Q21).

      • Rows (Q15) show activities respondents believe are important to disclose.
      • Columns (Q21) show activities for which respondents report using generative AI.
      • Each cell shows how many respondents report using genAI and disclosing such use for a given activity.

      Darker cells indicate stronger alignment between practice and disclosure, while lighter cells indicate weaker alignment. Because both questions (Q15 and Q21) allow for multiple selections, the heatmap graph also highlights broader patterns.

      Use the checkboxes to focus on specific activities and explore where norms of disclosure closely align or diverge from actual genAI use.

      How to Read This Graph

      This Sankey graph shows how respondents’ answers connect across different survey questions and so reveals how views, practices, and decisions tend to cluster or diverge.

      Each block represents a possible answer, and the flows between blocks show how many respondents chose both of those answers. Wider flows mean more respondents followed that same pathway.

      These flows make it easy to see where respondents’ perspectives and practices align, diverge, or take different directions rather than following a single pattern.
